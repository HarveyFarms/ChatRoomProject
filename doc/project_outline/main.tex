\author{Ryan H. and Eric S.}

\begin{document}
\maketitle
This project, from a high-level point-of-view, is an application that allows users to create chat rooms with each other. They can chat with others in their respective room through a text-based "terminal" display.

The details:
\begin{enumerate}
  \item Coded in C++ with Qt's libraries/APIs. % need to study this
  \item UI resembles a terminal
  \item User account creation/verification
  \item Chat room creation/joining/leaving
  \item Messages

    Attributes include: person sending it, chat room sent to, time stamp, and a string containing message content.

  \item Utilizes OO structure

    Users, messages, and chat rooms will all have their respective classes, inheriting and being the parent to other specific classes like a Moderator class.

  \item Utilizes network programming % need to study this

    Users can join/leave a server. This is how the chat room is made possible (communication among multiple computers). A server will maintain all currently connected users.

  \item Utilizes parallelism/concurrency

    A thread pool will handle the many requests to the server by executing tasks in parallel through multiple threads of control. For example, if two chat rooms are active at the same time, they should be operating simultaneously, especially since there data and interfaces are conflicting with each other.

  \item includes chat history

    Will store data in (?) (DB or file or in server)

  \item includes message search
\end{enumerate}
